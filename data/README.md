# Data

The session uses three interviews with singers from the Library of Congress's National Recording
Registry. They aren't stored here: the guide links to the Library of Congress's own copies,
because the Library generally doesn't own the rights to what it shares
(https://www.loc.gov/legal/).

- Dolly Parton (2016): https://www.loc.gov/static/programs/national-recording-preservation-board/documents/DollyPartonInterview.pdf
- Cyndi Lauper (2019): https://www.loc.gov/static/programs/national-recording-preservation-board/documents/CyndiLauperInterview.pdf
- Alicia Keys (2022): https://www.loc.gov/static/programs/national-recording-preservation-board/documents/Interview_Alicia-Keys.pdf

More interviews: https://www.loc.gov/programs/national-recording-preservation-board/recording-registry/index-of-interviews/
