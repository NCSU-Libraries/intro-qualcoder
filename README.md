# Introduction to QualCoder

Materials for NC State University Libraries' Introduction to QualCoder (Data Science Services), a
1-hour hands-on session. Attendees set up a project folder, install
[QualCoder](https://qualcoder.org/), a free, open-source program for qualitative data analysis,
create a QualCoder project, import interview transcripts, code them, add memos and annotations,
and run reports.

The guide is for QualCoder version 3.8.2. It's online at
https://ncsu-libraries.github.io/intro-qualcoder/qualcoder-workshop.html.

- `qualcoder-workshop.qmd`: the guide we work from in the session. Steps are in purple boxes,
  with tabs where Mac and Windows differ; everything else is explanation.
  `qualcoder-workshop.html` is the rendered, self-contained page.
- `data/`: the session's data: three Library of Congress interviews with singers (Dolly
  Parton, Cyndi Lauper, Alicia Keys) as plain text. They are copyrighted by their authors and
  shared with the Library of Congress's permission for noncommercial scholarly and educational
  use; they are not covered by the MIT license (see `data/README.md`).
- `images/`: our own screenshots of QualCoder, Finder and File Explorer.

Render the guide with `quarto render qualcoder-workshop.qmd`.
